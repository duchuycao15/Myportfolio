🛠️ Through this project, I was able to apply the skills I have gained over the years, including layout design, styling, user interface development, and basic interactivity.

🚀 This project also reflects my passion for programming and technology.
🕹️ I have always enjoyed the retro computer aesthetic, especially the classic Mac‑style interface, so I wanted to bring that inspiration into my portfolio.
🌟 By building this website, I was able to create something that not only presents my skills, but also shows my personality, creativity, and love for computer history and software design.

✨ Overall, this project represents my growth as a developer and my interest in creating websites that are both functional and visually memorable.
🛠️ It allowed me to practice my coding skills while also designing an experience that feels personal, creative, and inspired by the technology I enjoy.
